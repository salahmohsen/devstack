# Arc UI evaluation for the job pipeline

**Date:** 2026-11-02
**Status:** Research and recommendation. No code changed, nothing installed.
**Companion:** [Revenue strategy](./2026-11-02-revenue-strategy.md), section 9.

## How this was built

I read Arc's public machine-readable catalog at `uiarc.dev/r/catalog.json` (377 items, each with tier, description, props, "when not to use" notes, and dependencies), its [license](https://uiarc.dev/license), and its [pricing](https://uiarc.dev/pricing). I compared each item against what this repo already builds, using file listings and dependency checks.

**Limits.** Pro source is token-gated, so I judged items from their public docs, not their code. I did not install anything or test compatibility with your Base UI components. The $125 Egypt lifetime price is yours. My fetch of the pricing page showed $249, so the regional price probably appears at checkout. All ratings are my judgment.

## 1. Verdict

At $125 lifetime the money is small. It equals about 8 subscriber-months at the $19 Pro price after fees and AI cost (estimate). The real cost is integration time and a second styling system.

**Buy it, but only for a short list.** Of 234 Pro items, 11 are clearly worth using and 31 more are useful later. The other 192 are decorative, off-topic, or already built in your app. Of 81 AI-themed Pro items, 23 earn a place and 58 do not.

**Do not migrate the UI.** Use Arc as a parts bin for the screens you have not built yet. Those are billing, upgrade prompts, mail reply drafting, and a marketing site. Do not replace working screens.

**Buy when you start the billing work.** Revisit the purchase when you wire Polar, not today. Nothing in the first two weeks of the plan needs Pro.

## 3. Rating method

Each item gets one rating.

- **A, use.** It fills a screen you do not have. It needs little glue, and it supports revenue or activation within about eight weeks.
- **B, later.** It improves a screen you already have, or fills a gap that does not block launch. Adopt after paying users exist.
- **C, skip.** It is decorative, targets another product type, or duplicates something you already built.

Integration cost is Low, Medium, or High. Low means `motion` only and a data-in, callbacks-out interface. Medium means Radix or a wiring change. High means it conflicts with assistant-ui or replaces a working screen.

## 8. Cost of adopting, and a safe way to do it

**Estimated time (guess).** One A item with Low cost takes about half a day including theming. A Medium item takes a day. Using all 11 A items is about 6 to 8 days, and wiring them to Polar and the AI credit counter is separate work you owe anyway.

**What saves time.** The Arc MCP server and Arc's agent skill let Claude Code install and adapt items. The Pro skills include "Refactor to Arc" and audits. I have not tried them.

**Adopt in this order.**

1. **Before buying.** Install `arc-foundation`, `usage-meter`, and `plan-comparison` from the free registry in a throwaway branch. Check three things. Do CSS modules and Tailwind v4 coexist in your Vite build? Does Arc's `data-theme="dark"` attribute match how your theme switcher sets dark mode? Do tokens clash with your existing CSS variables? If any answer is bad, stop. You have spent nothing.
2. **Buy lifetime at $125 when you start billing.** Install `billing-overview`, `usage-billing`, `upgrade-prompt`, and `cancel-flow`. Scope them to a `features/billing` folder.
3. **Then the mail loop.** Install `reply-draft` and `tone-tuner` in the apply package and mail screens. Wire `generate` to your existing mail reply and cover letter endpoints.
4. **Then `response-feedback`** on hub answers, feeding Mastra feedback.
5. **Stop.** Review what moved the numbers before adopting any B item.

**Guardrails.**

- Keep every Arc file under one folder, `components/arc/`, so removing it is one deletion.
- Add the Arc Pro notice to each Pro file and a line in `LICENSE` or the README saying Pro files are not MIT. The license requires this because the repo is public.
- Do not re-export Pro files from `packages/ui`, since that package looks like a shared library.
- Do not let Arc's `ai-chat` or `ai-composer` anywhere near the hub, because they would fight assistant-ui for the stream.

## 9. Final recommendation

1. **Do not buy yet.** Run the free-tier compatibility test in step 1 above. It costs an hour.
2. **If it passes, buy lifetime at $125** when billing work starts, and use only the 11 A items.
3. **Do not migrate** any existing screen. The 31 B items wait for revenue.
4. **Use Arc's free tier for the marketing site.** It already has what a launch needs.
5. **Treat the AI Pro showcase as inspiration, not inventory.** Four of 81 AI items matter for this product.
